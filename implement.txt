1. 💬 ASK
   Questions / answers

2. ✍️ RECORD
   New data entry

3. ✏️ CORRECT
   Existing data correction

4. 🔍 AUDIT
   Find inconsistencies

   Reports / comparisons / insights

   Actual database changes

और EXECUTE mode में confirmation + permission + audit log mandatory रखो।
